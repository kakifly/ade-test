---
description: 検証が通るまで「直す → 再検証」を回す（1回に1点だけ直し、3回同じ失敗で止まる）
---

次の手順で、型チェックとすべてのテストが成功するまで、修復のループを回してください。

1. `bun run db:apply:test` のあと `bun run verify` を実行し、失敗した項目を読む（件数ではなく、失敗したテスト名・期待値・実際の値を読む）
2. 失敗の原因を1つ特定し、**1点だけ**直す（`CLAUDE.md`「失敗が続くときの歯止め」に従う）
3. 直し方は、テストを書き換える・削除する・スキップするものにしない。仕様（`docs/ai-input/`）が誤っているときは、仕様を先に直す
4. 再実行して、結果を比べる。失敗が減ったか、別の失敗に変わったかを、周回ごとに一言で記録する（`docs/experience-log.md` の第4章に書くのは、体験として残す価値があるときだけ）
5. 同じテストが**3回続けて**失敗したら、同じ直し方をやめる。`superpowers:systematic-debugging` で原因を調べ直す。それでも直らなければ、作業を止めて、失敗したテスト名・期待値と実際の値・試したことをユーザーに報告する
6. すべて成功したら、通った件数を報告して終える

直近の失敗の連続回数は `.claude/loop/failures.log` に記録されている（git管理外）。
